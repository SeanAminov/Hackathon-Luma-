🚨 Autonomous On-Chain Detective Agent
Real-Time Rugpull & Fraud Detection Using Agentic AI + Blockchain Monitoring
🏆 Overview

Autonomous On-Chain Detective Agent is a real-time, AI-powered blockchain security system designed to detect and predict rugpulls, scams, and malicious activity before they happen.

It combines:

Live blockchain monitoring

Multi-agent reasoning

Liquidity & wallet flow analysis

Light anomaly detection models

LLM-based explanations

Telegram/Discord alerts

This project is built for the 2025 Scoop AI Hackathon — Silicon Valley Bowl, with the objective of redefining crypto security using agentic AI.

🎯 Key Features
🔍 1. Real-Time Blockchain Monitoring

Subscribes to on-chain events via WebSocket:

Pending transactions

Liquidity pool updates

Token transfers

Owner privilege changes

🤖 2. Multi-Agent Architecture

Each agent plays a specialized role:

Agent	Role
Listener Agent	Connects to chain, streams live events
Pattern Agent	Detects classical rugpull patterns
Anomaly Agent	Flags unusual spikes in liquidity, transfers, mint/burn activity
Risk Agent	Computes rugpull probability (0–100)
Explainer Agent	Generates human-friendly summaries
Alert Agent	Sends Telegram/Discord alerts
📉 3. Rugpull & Scam Pattern Detection

The system detects:

Sudden liquidity withdrawal

Owner dumping tokens

Massive mint or burn events

Privilege misuse (unrenounced contracts)

High-risk wallet flows

Honeypot behavior

🧠 4. AI-Generated Explanations

LLM-powered reasoning transforms raw blockchain events into readable insights:

“High risk: Owner removed 82% of liquidity in one block and moved 25% of supply to an unknown wallet.”

📊 5. Live Dashboard

Streamlit dashboard includes:

Risk score

Event timeline

Wallet flow map

Alerts feed

Contract summary

📬 6. Instant Alerts

Telegram / Discord notifications for major security events.
